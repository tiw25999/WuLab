## Acceptance Criteria

### US1 — แสดงรายการสินค้า
- [ AC1 ] แสดงสินค้าครบ 3 ประเภท: เสาไฟฟ้าคอนกรีตอัดแรง (standard) / เสาเข็มคอนกรีตอัดแรง (preorder) / แผ่นพื้น Hollow Core (preorder)
- [ AC2 ] สินค้า preorder แสดง badge "สั่งผลิตพิเศษ" และระยะเวลา 7–14 วัน
- [ AC3 ] แสดง spec, ตารางราคา, ปุ่ม "ขอใบเสนอราคา" สำหรับสินค้าแต่ละประเภท
- [ AC4 ] filter ตาม category/type ได้

### US2 — ฟอร์มขอใบเสนอราคา
- [ AC1 ] แบ่ง 3 แบบตามประเภทลูกค้า: ทั่วไป / เอกชน (มีชื่อบริษัท) / ภาครัฐ (มีเลขหนังสือราชการ)
- [ AC2 ] เพิ่มรายการสินค้าได้หลายรายการพร้อมระบุจำนวนและหน่วย
- [ AC3 ] ระบบ generate รหัสอ้างอิง `SMC-YYYYMMDD-XXXX` อัตโนมัติหลัง submit
- [ AC4 ] แสดงหน้า confirm พร้อมรหัส SMC เพื่อให้ลูกค้านำไปติดตาม

### US3 — ติดตามสถานะด้วย SMC
- [ AC1 ] กรอก SMC code เดียวติดตามได้ตลอดทุก stage
- [ AC2 ] ยังไม่มีใบเสนอ → แสดง "กำลังจัดทำ" + รายการสินค้าที่ขอ
- [ AC3 ] มีใบเสนอราคาแล้ว แต่ยังไม่มี PO → แสดงวันหมดอายุ (เปลี่ยนเป็นสีแดงถ้า expired)
- [ AC4 ] มี PO แล้ว → แสดง 4-step timeline พร้อม status ปัจจุบัน

### US4 — Admin Dashboard
- [ AC1 ] Admin login ด้วย username/password + JWT cookie
- [ AC2 ] ดูรายการ RFQ ทั้งหมดเรียงตามวันล่าสุด
- [ AC3 ] filter: ทั้งหมด / ใหม่ / กำลังดำเนินการ / เสร็จสิ้น
- [ AC4 ] badge แสดง "ได้รับ PO แล้ว" สีเขียวเข้มสำหรับ inquiry ที่มี PO แล้ว

### US5 — สร้างใบเสนอราคา + PDF
- [ AC1 ] Admin กรอกราคา/หน่วยของแต่ละสินค้า ระบบคำนวณ subtotal, VAT 7%, total อัตโนมัติ
- [ AC2 ] กำหนดอายุใบเสนอราคา (วัน) และหมายเหตุได้
- [ AC3 ] generate รหัส `QT-YYYYMMDD-XXXX` + สร้าง link สำหรับส่งให้ลูกค้า
- [ AC4 ] ดาวน์โหลด PDF ใบเสนอราคาได้ มีฟอนต์ภาษาไทย (Sarabun) ครบถ้วน
- [ AC5 ] สร้างใบเสนอราคาใหม่ได้ (ราคาใหม่ + link ใหม่) หากยังไม่มี PO

### US6 — ลูกค้าดูใบเสนอราคา
- [ AC1 ] เปิด `/quotation?ref=QT-...` แล้วเห็นรายละเอียดสินค้า ราคา VAT ยอดรวมครบถ้วน
- [ AC2 ] แสดง status "รอรับ PO จากลูกค้า" (กล่องเหลือง) หรือ "ได้รับ PO แล้ว" (กล่องเขียว) + วันที่
- [ AC3 ] ดาวน์โหลด PDF และโทรหาทีมงานได้จากหน้านี้

### US7 — บันทึก PO
- [ AC1 ] Admin กรอกเลข PO ของลูกค้า + แนบไฟล์ PDF/JPG/PNG ได้
- [ AC2 ] ระบบ generate รหัส `PO-YYYYMMDD-XXXX` อัตโนมัติ
- [ AC3 ] สินค้า standard (ไม่ใช่ preorder) → ข้ามขั้น "กำลังผลิต" ไปที่ "กำลังจัดส่ง" ทันที
- [ AC4 ] หลังบันทึก PO สำเร็จ → redirect ไปหน้า Kanban อัตโนมัติ

### US8 — Kanban Board
- [ AC1 ] แสดง 4 column: ได้รับ PO / กำลังผลิต / กำลังจัดส่ง / จัดส่งแล้ว
- [ AC2 ] ย้าย card ระหว่าง column ได้ด้วยปุ่ม "ย้ายไป" หรือ drag-and-drop
- [ AC3 ] แต่ละ card แสดงชื่อลูกค้า, มูลค่าออเดอร์, วันที่รับ PO
- [ AC4 ] กดปุ่ม "จัดการ" ใน card → ไปหน้า RFQ detail เพื่อดูรายละเอียดเพิ่มเติม
