## 4. แผน MVP ภายใน 1 วัน

| ช่วงเวลา | Task | รายละเอียดงาน | ผลลัพธ์ที่ได้ |
|----------|------|--------------|-------------|
| 08:00 – 09:00 | **T1 ตั้งค่าโปรเจกต์** | สร้าง Next.js 14 + Tailwind CSS<br>เชื่อมต่อ Prisma + SQLite<br>สร้างตารางสินค้าและคำขอ<br>ใส่ข้อมูลสินค้า 3 รายการเริ่มต้น<br>Push ขึ้น GitHub | โปรเจกต์รันในเครื่องได้ มีข้อมูลสินค้าพร้อม |
| 09:00 – 11:00 | **T2 หน้าแรก + เกี่ยวกับเรา** | Hero: โลโก้ ชื่อบริษัท สโลแกน ปุ่ม CTA<br>จุดเด่น 4 ข้อ + ใบรับรอง มอก.<br>ประวัติบริษัท 30 ปี<br>เมนูนำทางครบ | หน้าแรกและเกี่ยวกับเราสมบูรณ์ |
| 11:00 – 13:00 | **T3 แคตาล็อกสินค้า** | หน้ารายการสินค้าทั้ง 3 รายการ<br>ใส่รูปภาพจริงจาก `images/`<br>หน้ารายละเอียดสินค้าแต่ละรายการ + สเปค<br>ปุ่มดาวน์โหลดใบสเปค PDF | แสดงสินค้าครบทุกรายการ พร้อมรูปจริงและสเปค |
| 13:00 – 14:00 | **พักกลางวัน** | — | — |
| 14:00 – 16:00 | **T4 ฟอร์มขอใบเสนอราคา** | ฟอร์มแยก 3 กลุ่มลูกค้า (สลับได้)<br>ตรวจสอบข้อมูลก่อนส่ง<br>บันทึกลงฐานข้อมูล + รหัสอ้างอิง<br>ส่งอีเมลแจ้งเตือนผู้ดูแลระบบ<br>หน้ายืนยันพร้อมรหัสอ้างอิง | รับคำขอจากลูกค้าได้จริง มีอีเมลแจ้งเตือน |

## 6. เกณฑ์รับงานแต่ละระยะ

### ระยะที่ 1 — MVP
- [ ] หน้าแรก แสดงบริษัทและจุดเด่นครบถ้วน
- [ ] แคตาล็อกสินค้า 3 รายการ พร้อมรูปจริงและดาวน์โหลด Datasheet ได้
- [ ] ส่งฟอร์มขอใบเสนอราคาได้จริง และอีเมลแจ้งเตือน Admin
- [ ] แสดงผลถูกต้องบนมือถือและคอมพิวเตอร์
- [ ] เว็บไซต์ออนไลน์บน Vercel มีลิงก์จริง

### ระยะที่ 2 — ระบบขาย
- [ ] Admin เข้าสู่ระบบและจัดการคำขอครบถ้วน
- [ ] แก้ไขข้อมูลสินค้าผ่านหน้า Admin ได้
- [ ] ลูกค้าตรวจสอบสถานะด้วยรหัสอ้างอิงได้
- [ ] ส่งออกรายงาน Excel ได้
- [ ] ผ่านการทดสอบครบทุกฟีเจอร์

### ระยะที่ 3 — พื้นที่ลูกค้า
- [ ] ลูกค้าเอกชนสมัครและเข้าสู่ระบบได้
- [ ] ดูประวัติคำขอและสถานะได้ถูกต้อง
- [ ] ลูกค้าภาครัฐดาวน์โหลดเอกสารได้
- [ ] ระบบทั้งหมดทำงานได้บน Production

## 7. ข้อจำกัดและสมมติฐาน

### ข้อจำกัด
- ไม่มีระบบจัดการราคาอัตโนมัติ — กรอกราคาเองในระบบ
- ไม่เชื่อมต่อกับโปรแกรม ERP หรือระบบภายนอก
- ระยะที่ 1 ยังไม่รองรับการชำระเงินออนไลน์
- ระยะที่ 1 ยังไม่มีระบบสมาชิกสำหรับลูกค้า

### สมมติฐาน
- มีรูปภาพสินค้าจริงพร้อมใช้งาน (11 รูป ใน `images/`)
- มีไฟล์ Datasheet PDF ของสินค้าทั้ง 3 รายการ
- มีบัญชีอีเมลสำหรับรับแจ้งเตือนคำขอ
- เนื้อหาภาษาอังกฤษจัดทำโดยทีมงาน
